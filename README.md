# 番茄小说下载器

一个在本机浏览器中使用的番茄小说工具，支持分类浏览、关键词搜索、作品详情、章节阅读，以及按章节范围下载 UTF-8 TXT。章节解码表来自项目最初提供的脚本。

## 运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm start
```

打开 <http://127.0.0.1:3000>。可用 `PORT=其他端口` 和 `HOST=监听地址` 配置服务；默认仅监听本机。

## 使用

左侧点击大类可展开或收起子分类。也可以在顶部搜索书名、作者。点击书籍查看简介与目录。点击章节阅读；输入起止章节后点击“下载 TXT”保存文本。下载期间可取消；个别章节失败时，失败清单会附在文件末尾。

点击顶部“Cookie 设置”，每行粘贴一个已登录账号的完整 Cookie，保存后阅读和下载章节会依次轮换使用。Cookie 仅保存在当前浏览器的本地存储中，不写入项目文件或 Git。请仅使用自己有权使用的账号 Cookie；不要在共用电脑上保存。

程序依赖番茄小说当前公开页面及接口。网站结构、访问限制或章节权限变化时，分类、正文或下载可能无法使用。请尊重作品版权及平台规则，仅下载自己有权访问的内容。
