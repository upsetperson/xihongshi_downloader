# 番茄小说下载器

一个可在 Windows 上运行的番茄小说桌面客户端，支持分类浏览、关键词搜索、作品详情、章节阅读，以及按章节范围下载 UTF-8 TXT。也保留浏览器运行方式。章节解码表来自项目最初提供的脚本。

## Windows 客户端

支持 Windows 10 / 11（64 位）。构建后，`dist/` 中提供：

- `XihongshiDownloader-1.0.0-Setup-x64.exe`：安装版，可选择安装目录，创建桌面和开始菜单快捷方式。
- `XihongshiDownloader-1.0.0-Portable-x64.exe`：免安装版，双击运行。

使用客户端不需要安装 Node.js。浏览、搜索、阅读和获取章节需要联网。下载 TXT 时显示 Windows 保存对话框，可自行选择保存位置。客户端仅允许一个实例运行，再次打开会激活已有窗口。

设置和 Cookie 保存在当前 Windows 用户的 `%APPDATA%/xihongshi-downloader/` 下，重启和升级后保留。免安装版也使用该目录。桌面版与浏览器版分别保存设置，首次使用桌面版需重新配置 Cookie。

构建产物未做代码签名，Windows 可能显示未知发布者提示。正式分发时需启用可执行文件签名并配置代码签名证书。

## 开发和打包

开发和打包需要 Node.js 22.12 或更新版本。

```bash
npm install
npm start
```

`npm start` 打开桌面客户端。运行 `npm run build:win` 生成 Windows x64 安装版和免安装版；`npm run pack:win` 仅生成 `dist/win-unpacked/`，其中的 EXE 需要与同目录资源一起使用。首次安装依赖和打包时需联网下载 Electron 和 NSIS 工具。

运行 `npm test` 执行服务测试；`npm run test:desktop` 实际启动两次 Electron，检查页面、隔离配置、TXT 保存和设置跨重启保留。

## 浏览器模式

运行 `npm run start:web`，打开 <http://127.0.0.1:3000>。可用环境变量 `PORT` 和 `HOST` 配置服务；默认仅监听本机。PowerShell 示例：`$env:PORT=3001; npm run start:web`。桌面模式自动选择空闲端口，不受这两个环境变量影响。

## 使用

左侧点击大类可展开或收起子分类。书库区域可以筛选读者、分类、连载状态和字数，并按最热、最新或字数排序；默认展示截图示例的“女生 → 主题 → 古言权谋 → 已完结 → 30-50万”。也可以在顶部搜索书名、作者。点击书籍查看简介与目录，目录每页显示 60 章，可跳转到指定章节区间。阅读窗口支持纸张、暖色和夜间主题，以及字号、行距和阅读宽度设置，设置保存在当前浏览器。输入起止章节后点击“下载 TXT”保存文本。下载期间可取消；个别章节失败时，失败清单会附在文件末尾。

点击顶部“Cookie 设置”，每行粘贴一个已登录账号的完整 Cookie，保存后阅读和下载章节会依次轮换使用。Cookie 仅保存在当前客户端或浏览器的本地存储中，不写入项目文件或 Git。请仅使用自己有权使用的账号 Cookie；不要在共用电脑上保存。

程序依赖番茄小说当前公开页面及接口。网站结构、访问限制或章节权限变化时，分类、正文或下载可能无法使用。请尊重作品版权及平台规则，仅下载自己有权访问的内容。
